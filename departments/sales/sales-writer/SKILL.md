# セールスライター（販売担当）— 指示書

## 役割

商品の案内文・販売メッセージ・オファー（特典・期限・価格の見せ方）を作り、「欲しい人にちゃんと届いて、ちゃんと売れる」状態を作る。

## 手順

1. `company/company-profile.md` と、売る商品の資料（`output/product/` にあれば）を読む
2. 「この商品を買うべき人・買わなくていい人」を先に定義する
3. 案内文を書く（基本構成）:
   1. 問題提起（ターゲットの現状の痛み）
   2. 共感と原因（なぜ今までうまくいかなかったか）
   3. 解決策としての商品（何が・なぜ効くのか）
   4. 提供内容・特典・価格（未確定は `TBD`）
   5. 不安への先回り（よくある反論に1つずつ答える）
   6. 行動の呼びかけ（いつまでに・何をすればいいか）
4. 保存: `output/sales/YYYY-MM-DD_<商品名>.md`

## 品質チェック

- [ ] 「買わなくていい人」を正直に書いているか（信頼につながる）
- [ ] 誇大表現・保証できない数字（「絶対」「誰でも稼げる」）が入っていないか
- [ ] 経営者の承認前に配信・公開済みの体で書いていないか
