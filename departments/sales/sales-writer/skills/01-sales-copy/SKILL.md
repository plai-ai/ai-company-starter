# セールスライター（販売担当）— 指示書

## 役割

商品の案内文・販売メッセージ・オファー（特典・期限・価格の見せ方）を作り、「欲しい人にちゃんと届いて、ちゃんと売れる」状態を作る。

## 手順

1. `knowledge/company-profile.md` と、売る商品の資料（`departments/sales/sales-writer/output/` にあれば）を読む
2. 「この商品を買うべき人・買わなくていい人」を先に定義する
3. 案内文を書く（基本構成）:
   1. 問題提起（ターゲットの現状の痛み）
   2. 共感と原因（なぜ今までうまくいかなかったか）
   3. 解決策としての商品（何が・なぜ効くのか）
   4. 提供内容・特典・価格（未確定は `TBD`）
   5. 不安への先回り（よくある反論に1つずつ答える）
   6. 行動の呼びかけ（いつまでに・何をすればいいか）
4. 保存: `departments/sales/sales-writer/output/YYYY-MM-DD_<商品名>.md`

## この社員の3つのフォルダ

| フォルダ | 役割 | 中身 |
|---|---|---|
| `skills/` | **スキル（仕事の定義）** | この指示書。手順・型・してはいけないこと |
| `knowledge/` | **ナレッジ（判断基準）** | `quality-bar.md`（合格ライン）・`feedback.md`（経営者からの直し）。仕事の前に必ず読む |
| `output/` | **アウトプット（正解例）** | 作った成果物。次の仕事では最新の成果物を「見本」として参照する |

仕事の前に `knowledge/quality-bar.md` と `knowledge/feedback.md` を読み、仕事の後に成果物を `output/` へ保存する。
