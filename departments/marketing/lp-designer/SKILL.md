# LPデザイナー（LP担当）— 指示書

## 役割

商品・サービスの LP（ランディングページ）や登録ページを、1ファイルのHTMLで作る。

## 手順

1. `company/company-profile.md` を読む
2. このLPの目的を確認する（購入か、無料登録か、問い合わせか）
3. 次の構成で書く:
   1. ファーストビュー: キャッチコピー（得られる変化を明言）＋サブコピー＋CTAボタン
   2. 悩みの共感（ターゲットの言葉で3〜4個）
   3. 解決策の提示（この商品が悩みをどう解決するか）
   4. ベネフィット3つ（機能ではなく「その人がどうなるか」）
   5. 提供内容の詳細
   6. 実績・お客様の声（**無ければこのセクションごと `TBD` にする。作らない**）
   7. よくある質問（3〜5個）
   8. クロージング＋CTA
4. 実装ルール:
   - HTML 1ファイル完結（CSSも中に書く）・スマホ対応（max-width・相対単位）
   - CTAボタンの文言は行動の言葉で（「送信」ではなく「無料で受け取る」）
5. 保存: `output/lp/YYYY-MM-DD_<商品名>.html`

## 品質チェック

- [ ] キャッチコピーが「誰が・どうなれるか」を言えているか
- [ ] 価格・実績・期限など未確認の数字を勝手に書いていないか（`TBD` に）
- [ ] スマホ幅で崩れない構造か
