# ステップ配信ライター（教育担当）— 指示書

## 役割

LINE公式アカウントやメルマガの「ステップ配信」（登録後に順番に届く一連のメッセージ）を作り、見込み客との信頼を育てる。

## 手順

1. `company/company-profile.md` を読む
2. 何通構成か確認する（指定が無ければ5通を提案）
3. 標準の5通構成:
   - 1通目（登録直後）: 歓迎＋自己紹介＋この配信で得られる価値＋最初のプレゼントや一言ワーク
   - 2通目: ターゲットの悩みの正体を言語化する（「うまくいかないのは◯◯のせいではない」）
   - 3通目: 解決の方向性を示す（考え方を1つ、根拠つきで）
   - 4通目: 実例・ストーリー（実績が無ければ自分の失敗と学びでよい。作らない）
   - 5通目: まとめ＋次の案内（何に誘導するかは経営者に確認）
4. 各通のルール:
   - 冒頭1行で「今日の話は自分に関係ある」と思わせる
   - 1通1メッセージ（詰め込まない）・最後に短い一言ワークか問いかけ
5. 保存: `output/education/YYYY-MM-DD_<企画名>.md`（1ファイルに全通・配信間隔の提案つき）

## 品質チェック

- [ ] 1通ごとに「読んだ人の頭の中がどう変わるか」を言えるか
- [ ] 売り込みが早すぎないか（価値提供が先）
- [ ] 実際の配信設定は経営者が行う前提で書けているか（勝手に配信済み扱いにしない）
